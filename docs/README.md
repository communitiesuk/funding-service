# Funding Service technical documentation

This directory holds Request For Comments (RFCs) and Architecture Decision Records (ADRs) relevant to the implementation of the Funding Service technical architecture. It should document key decisions, discussions and options explored for important parts of the platform.

This replaces the separate [funding-service-requests-for-comment](https://github.com/communitiesuk/funding-service-requests-for-comments) repository, which is now archived.

## Adding images
We avoid adding large image files to the repository directly. The workaround I've taken for now is to upload images to a page on the unused [GitHub Wiki](https://github.com/communitiesuk/funding-service/wiki/RFC-images) and including asset URLs from there in the relevant markdown documents.
